
## 📖 概要
**「必要な期間だけ残して、あとは忘れる」**
選択した期間（日、週、月、年）が経過すると、自動的に写真を削除するメモ用カメラアプリです。
一時的なメモや、短期的な記録に最適です。

## ✨ 特徴
* 自動削除機能: 保存期間を設定して撮影することで、期限切れの写真を自動整理。
* シンプルな操作: 期間を選んでシャッターを切るだけの簡単UI。
* 期間設定: 用途に合わせて4つの期間から選択可能。

## 📱 動作環境 (Requirements)
* **OS**: iOS 16.0 以上
* **Device**: 実機での動作（カメラ機能を使用するため）
* **Language**: Swift

## 🛠 環境構築 (Installation)

以下の手順でプロジェクトをローカル環境にセットアップできます。

1. リポジトリをクローンします。
   ```bash
   git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
   ```
2.  Xcodeでプロジェクトファイル（`.xcodeproj`）を開きます。
    ```bash
      cd your-repo-name
      open [アプリ名].xcodeproj
    ```
3.  署名（Signing）の設定を自身のTeamに変更します。
4.  実機をPCに接続し、ビルド・実行してください。

## 🚀 使用方法 (Usage)

### 1\. 期間を選択して撮影

画面下部のボタンから、保存したい期間を選択してから撮影ボタンを押してください。

| ボタン | 期間 | 用途イメージ |
| :---: | :--- | :--- |
| **d** | Day (1日) | 今日の買い物メモ、駐車位置など |
| **w** | Week (1週間) | 今週の課題、一時的な掲示物など |
| **m** | Month (1ヶ月) | 月次の支払い票、シフト表など |
| **y** | Year (1年) | 年間パスポート、長期保存したい控えなど |

### 2\. 写真の確認

  * 画面左下のプレビュー画像をタップすると、アルバム画面へ遷移します。
  * 保存されている写真の一覧を確認できます。
